# 🧠 FindJob — Job Posting Web App

A full-stack web application that allows users to **add and view job posts**.  
Built with **React (Vite)** for the frontend and **Spring Boot** for the backend.  
It provides a simple interface to manage job posts along with their required technologies and experience levels.

---

## 🚀 Features

- 📝 Add, view, and manage job posts  
- 🔗 Many-to-many relationship between jobs and technologies  
- ⚙️ RESTful API built with Spring Boot  
- ⚡ Fast and modern frontend using React + Vite  
- 🌐 API requests tested using Postman (or any REST client like Hoppscotch or Thunder Client)

---

## 🧰 Tech Stack

### **Frontend**
- ⚛️ React (with Vite)
- 🎨 TailwindCSS
- 🔄 Axios (for API calls)
- 🔧 Vite Proxy setup for connecting with Spring Boot

### **Backend**
- ☕ Spring Boot
- 🐘 PostgreSQL
- 🧱 JPA / Hibernate
- 🔐 Spring Data REST
